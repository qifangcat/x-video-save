# X 视频保存

一个用于 X（原 Twitter）Android 客户端的 LSPosed 模块，在视频播放栏提供下载入口，可将支持的视频保存到设备本地。模块的作用域仅为 `com.twitter.android`，下载在本机 X 进程内完成，不发送到第三方服务。

## 功能

- 在视频播放栏倍速按钮右侧显示“↓”入口，轻点按原画下载。
- 长按入口可选择本次下载画质，或单独设置播放画质。
- 视频保存到 `Movies/X视频保存/`；下载时显示画面或声音分片的阶段进度。
- 最多同时下载两条任务，其余任务排队。

## 环境与使用

需要 Android 设备、X 官方客户端和可用的 LSPosed 环境。从 [Releases 发布页](https://github.com/qifangcat/x-video-save/releases)下载 APK，也可自行编译。安装后在 LSPosed 中启用模块并将作用域设为 X，重启 X 后进入视频播放页面，播放几秒即可使用下载入口。

适配目标：手机 Android 16、LSPosed 2.1.0、X 12.41.0-prod.01，以及平板 Android 13、LSPosed 1.9.2、X 12.42.0-prod.01。模块会根据播放器方法签名查找两版对应结构；X 后续更新仍可能需要重新适配。其他组合的兼容性未全面验证。

## 已知限制

- 下载入口作为 X 播放栏中倍速旁的控件参与布局；它依赖当前 X 版本的内部实现，X 更新后可能需要重新适配。暂停状态依赖最近活动的可见播放器。
- 支持无加密、完整的 HLS 点播和直接 MP4；不支持直播、加密视频、带字节范围或时间线不连续的 HLS。其他来源、私信视频或其他格式未验证。
- CDN 可能返回 403 或地址失效；不会把失败的下载保存为完整视频。下载需要保持 X 进程运行。
- Android 13 及更早版本使用 mp4parser 合并 HLS 分片，以避免部分设备的系统媒体解析器崩溃；Android 14 及以后沿用系统合并器。依赖 `org.mp4parser:muxer:1.9.56`，采用 Apache 2.0 许可。
- 当播放器提供 HLS 主播放列表时，原画选择分辨率面积最大的一档；高清和标清分别选择短边不超过 720 或 480 像素的最高可用档位。没有符合条件的档位时使用最低可用档位并提示；分辨率未知时不能选择高清或标清。相同分辨率优先较高码率，不重新编码。播放器直接提供 MP4 时只能保存原有版本。
- 播放画质可单独设置为跟随 X、优先最高、高清或标清；实际播放仍受视频源、设备与网络限制，较高画质可能缓冲。
- APK 使用本机 Android debug 签名；若将来换机器编译，签名变化会影响覆盖安装。请保留本机 debug 签名密钥。

## 编译

需要 Android SDK 36、JDK 21、Gradle 9.4.1。设置 `ANDROID_JAR` 指向 SDK 中的 `platforms/android-36/android.jar`，并在 `local.properties` 设置 `sdk.dir`，运行 `gradle assembleDebug`。模块产物位于 `app/build/outputs/apk/debug/app-debug.apk`。`xposed-stubs` 仅用于编译，未打包进 APK，运行时由 LSPosed 提供接口。
