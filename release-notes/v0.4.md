## 更新内容

- 支持下载中断后继续：网络出错时自动重试；失败后重新打开同一视频并选择相同画质，可复用未被清理的缓存。
- HLS 复用已完成的分片；直接 MP4 和未完成的分片在服务器支持续传并提供校验信息时，可从已有数据继续。媒体地址变化、缓存被清理或服务器不支持安全续传时，受影响的文件需要重新下载。
- 下载完成后清理本次任务缓存；未完成的视频不会发布到相册。

## 安装与验证

- 单个 APK 适配目标：Android 16 / X 12.41 或 12.42 手机和 Android 13 / X 12.42 平板；其他版本未全面验证。X 更新后可能需要重新适配。
- 在 Android 16 / X 12.42 手机测试了 HLS 下载：模拟网络中断后重新点击下载，观察到已完成分片复用、未完成分片增长，并成功保存视频。成品前 10 秒音视频解码通过；未抓取 HTTP Range 响应，也未人工试听。
- 直接 MP4 的断点续传和平板真机续传尚未验证。下载需要保持 X 进程运行；CDN 地址失效或返回 403 时可能无法继续。
- 使用 LSPosed，作用域选择 X。构建类型为 debug，使用与 v0.1 相同的 Android debug 签名，可覆盖安装相同签名的旧版；签名文件不随 APK 发布。
