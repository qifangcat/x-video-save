## 更新内容

- 播放画质菜单显示当前分辨率、可用分辨率和播放器及源列表提供的标称码率。
- 可选择设备支持的最高码率轨道，并比较当前轨道和源列表中的标称峰值。
- 标称码率不是实时网速；最高画质受视频源、设备和播放器限制。

## 安装与验证

- 单个 APK 适配目标：Android 16 / X 12.41 手机和 Android 13 / X 12.42 平板；其他版本未全面验证。
- 手机和平板已实际检查播放画质菜单与最高档选择；本次手机复测未测试下载。平板此前已验证 HLS 下载合并。
- 使用 LSPosed，作用域选择 X。构建类型为 debug，使用与 v0.1 相同的 Android debug 签名，签名文件不随 APK 发布。
- X 内部实现可能随客户端更新变化；仅支持无加密、完整的 HLS 点播和直接 MP4。
